Privacy policy

Last updated: 11 November 2026.

Kindle dash is a personal project used only by its owner.

Data accessed

With the owner's consent it reads, read-only, Google Calendar events (calendar.readonly) and Google Tasks (tasks.readonly) of the owner's own Google account. It never creates, changes or deletes anything.

Use and storage

The data is used only to draw a dashboard image on the owner's own e-ink display. It is processed and stored only on the owner's Raspberry Pi inside a private home network, kept as a short cache of the next 30 days, and overwritten every hour.

Sharing

The data is not sold, shared, transferred to third parties, used for advertising, or used to train any model. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the Raspberry Pi removes all stored access.
